# HueVistaa Partner

The phone app for the businesses that sell and apply HueVistaa colours: **paint shops** and
**painters**. One app, one sign-in. The account decides which side opens:

- **A shop** (its owner, or the person they trust with the shop's account) sees what needs an
  answer today: price questions from the staff, asks for leave, who is in, and painters' claims.
- **A painter** has their points, the shops they buy from, rewards and their own work books.

Shop staff use their own app, **HueVistaa Staff**, and homeowners use **HueVistaa**.

It talks to the same backend as the website and the other apps (`api.huevistaa.com`).

The app itself is being built on a branch and arrives through a pull request.
